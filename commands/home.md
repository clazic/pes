argument-hint: "[새 폴더]"

`pes:core`의 CLI. 인자: $ARGUMENTS

- 인자가 없으면 `home`을 실행해 현재 PES 홈과 프로젝트 수를 보여 준다.
- 인자가 있으면 먼저 `home`과 `list`로 무엇이 옮겨질지 보여 주고, 옮길 프로젝트 수와 새 위치를 한 줄로 알린 뒤 `home <새 폴더>`를 실행한다 (사용자가 이 명령으로 요청한 것이므로 다시 묻지 않는다).
- 실패하면(이름 충돌·다른 세션 사용 중) 출력 그대로 알리고 멈춘다.
- 성공하면 새 주소들을 알리고, 이 세션이 지켜보던 feedback.log Monitor가 있으면 새 경로로 다시 건다.
- 경로에 공백·한글이 있으면(예: `OneDrive - 회사명`) 따옴표로 감싼 그대로 넘긴다. 클라우드 동기화 폴더로 옮겼으면 README 「OneDrive로 옮기기」의 '항상 이 장치에 유지'와 '한 번에 한 컴퓨터' 안내를 한두 줄로 덧붙인다.
