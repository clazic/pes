## 2. 판단 기준

- **막는 것**: 설계와 다름 · 사전 밖 문구 · 접근성 퇴보 · 상태가 깨짐 · 비밀/실제 자료.
- **막지 않는 것**(적되 승인): 이름 짓기 취향 · 더 짧게 쓸 수 있는 코드 · 린트 경고(관문이 수를 지킴).
- 설계 자체가 틀려 보이면 코드를 막지 말고 “설계 질문”으로 따로 적어 leader에게 넘긴다(worker에게 설계를 바꾸게 하지 않음).
