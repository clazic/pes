# 2. tester — 대시보드 7차 시험 설계서

- 모델: Claude Code · Sonnet 5.5. **작성 모드**(구현 전 — 새 요구를 지키는 **실패하는 시험**과, 지금 동작을 지키는 **회귀 시험**을 구분해 커밋) · **보강 모드**(관문 PASS 뒤 — 빠진 경우를 더해 `BUG` 또는 `HARDENED`로 보고).
- 근거: [dashboard-v2.md](../dashboard-v2.md) 18절, [1-leader.md](1-leader.md) 이슈 표, 공통 규칙 [README](README.md). Codex 검수 반영(2026-11-10, 필수 2 · 5 · 7 · 8 · 10, 권장 4).
- 하지 않는 것: 구현 코드 · 설정 · `package.json` 고치기(관문 3번이 막는다 — 시험 도구 설치는 UI7-0a에서 worker가). 시험 기대값을 근거 없이 약하게 바꾸기 — 관문은 이것을 못 잡으므로 **leader와 리뷰어가 diff로 심사**한다. 실패시키려고 일부러 기대값을 바꾸지도 않는다.

## 1. 시험 도구

- UI7-0a(worker)가 Vitest + `@testing-library/react` + `user-event` + jsdom, `npm test`, `scripts/lint-budget.mjs`를 만든다. tester는 UI7-0b부터.
- 시험 파일: 고칠 파일 옆 `*.test.ts(x)`. 합성 자료만(`src/mocks`).
- 브라우저 실측(두 폭 · 줄 수 · 대비)은 지금은 leader 수동 확인. 자동화(Playwright)는 실제 앱(U1)에서 정한다.

## 2. 이슈별 시험

### UI7-0b — 바탕 회귀 시험 (지금 통과해야 정상)

| 시험 | 기대 |
|---|---|
| `cn("bg-primary text-primary-foreground", "text-meta")` | `text-primary-foreground` 남음(“정리하기” 단추 버그 재발 방지) |
| `cn("text-meta", "text-body")` | `text-body`만 |
| `approvalBlockers` — 필수 질문 미응답 막힌 것 + 사유 “필수 답 1개 없음” + **다른 사유 1개** | 사유에서 “필수 …”만 빠짐, total = 남은 사유 1 + 막힌 것 수 |
| `approvalBlockers` — 막힌 것 없음 | reasons 그대로, blocking 0 |

### F1 · F2 · F3 — 시안 고칠 일 (실패 시험)

- **F1**: 라운드 화면(1280+ 흉내 · 접힘 기본)에서 결과 글 “AI에게 부탁”(문단 2) → AI 동료 칸이 보이고 · 부탁할 곳 = “문단 2” · 부탁할 말 칸에 초점 · `sessionStorage` 펼침. 1280 미만은 판이 열림(지금 동작 회귀).
- **F2**: 같은 합성 자료에서 개요 · 지금 할 일 머리 · 승인 카드가 **같은 수, 같은 이름 “승인을 막는 것 n건”**.
- **F3**: 사용량 맨 위 줄 — 확인 유효 · 확인 만료 · 확인 없음 · 과금 표시 · 종량제 상한 있음 · 상한 없음 · 연결 없음 7경우 문구(18.6). “지금 추가로 돈이 나가고 있지 않습니다” 0건.

### UI7-1 — 카드 변형

- `<Card size="compact">`의 클래스에 정한 여백 · 간격, 기존 `size="sm"` · 기본은 그대로(회귀). 경고 수는 관문의 `lint-budget`이 본다.

### UI7-2 — React 경고 (동작 보존 회귀 시험 — 고치기 전에 커밋, 지금 통과)

경고가 있는 파일마다 바뀌면 안 되는 동작: `useDraft` 초안 읽기 · 쓰기 · 탭 바뀜 / `ConfirmDialog` 열 때 이유 칸 초기화 · 본인 확인 단계 / `controls` 스위치 요청 흐름 / `use-mobile` 폭 바뀜 / 자료 거르기 · 업로드 대화 상자 / 사용량 `#ops` 해시 탭 / 설정 정책 대화 상자 / AI 부탁 대상 문단 / 막힌 것 보드 펼침 / 라운드 화면 “마쳤습니다”(본 단계가 사라졌을 때) · “보냄” 카드 / 차례 표시기 경과 글자. 렌더가 늘지 않는지 필요한 곳만 센다.

### UI7-3 — 개요 칸

- 자동 시험은 클래스 회귀만. **완료 판정은 leader 수동 확인**: 1440 · 시안 합성 문구에서 현재 단계 상태 글자 2줄 이하(지금 시안은 4줄 — 먼저 그 실패를 확인해 PR에 적음).

### UI7-4a · 4b — 설계 확인 뒤

- 4a: 질문 카드 초점에서 `1`~`4` 선택 · 입력 칸 / 한글 조합 / 대화 상자 열림이면 무시 · 끄기 설정 · `Ctrl/⌘+Enter` = 검토 대화 상자 열기(바로 보내지 않음).
- 4b: 판단 전 제안만 · 확인 한 번 · 권한 없음 · 일부 실패 시 남은 것과 결과 표시.
