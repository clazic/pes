1. PES가 무엇이 되나

파일 한 장에 적던 것을, 서랍장(DB)과 웹 화면으로 나눕니다.

2. AI가 일하는 두 가지 방식

둘 다 같은 DB, 같은 API를 씁니다. 다른 것은 AI가 어디서 도느냐입니다.

방식 A

PES가 AI를 직접 부릅니다 — 내 컴퓨터 필요 없음

방식 B

내 컴퓨터의 AI가 만들고, 웹에서 이어서 작업합니다

통로누가 누구와하는 일하지 않는 일
웹소켓PC 도우미 ↔ 웹 PES새 작업·자료·답 알림, 진행·스케줄·동기화큰 파일 전송, A 실행
MCPAI 도구 6가지 ↔ PES맥락 읽기, 결과 제출, 질문PC↔웹 실시간 통로 자체, 사람 답 대행
WebMCP브라우저 탭 AI ↔ 열린 PES 화면제한된 읽기·초안·첨언PC↔웹 통로, 승인·정책·토큰·사람 답

큰 파일은 웹소켓이 아니라 HTTP 업로드/다운로드(R2·Blob 서명 URL)로 오갑니다. 직접 연결이 안 되는 앱은 복사·붙여넣기 전달을 보장 경로로 둡니다.

3. 새로 붙는 두 가지

이전 프로젝트를 참고하고, 내 자료를 올려 AI가 볼지 파일마다 정합니다.

MAT1
