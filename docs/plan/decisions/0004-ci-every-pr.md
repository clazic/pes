# 0004. CI는 매 PR과 main에서 Windows·macOS로 돌린다

- 날짜: 2026-11-04
- 담당: SEL-15

## 문제

회귀를 늦게 발견하면 0단계의 테스트 격리·복원 검증이 무너진다. 특히 Windows의 경로·한글·줄바꿈 차이는 macOS만으로 잡히지 않는다.

## 선택지

1. main에만 돌린다.
2. 매 PR과 main에서 Windows·macOS로 돌린다.
3. 로컬 테스트만 둔다.

## 채택

2번. 공개 저장소에서 **매 PR + main**, **Windows·macOS**. 브라우저가 필요한 시험은 Windows CI에 브라우저를 설치해 실행하고, 없으면 실패로 처리한다(3단계 이후).

## 이유

- 0단계 게이트가 "한 명령 테스트"와 "Windows/Mac CI"를 요구한다.
- PR 단위로 막아야 2단계 이후 대량 PR에서 회귀를 싸게 잡는다.
- 새 세션이 `AGENTS.md`만 보고 같은 검사를 재현할 수 있어야 한다.

## 영향

- SEL-15, `AGENTS.md`의 검사 절, 새 세션의 재현 절차.
- CI가 도는 저장소는 공개다(0008).
- 3단계 이후 Playwright Windows 필수 조건도 이 결정을 승계한다.

## 재검토 조건

- CI 시간·비용이 개발을 막을 정도가 될 때(그래도 main은 유지한다).
- Windows·macOS 외 지원 OS가 필요해질 때.
- 공개 저장소 정책이 바뀔 때(0008).
