# 0005. 5단계 웹은 지금은 Cloudflare 무료 요금제로 설계

- 날짜: 2026-11-05
- 담당: 5단계 WEB1~WEB14(예정), `stage-5.md`

## 문제

5단계에서 로컬 PES를 공개 HTTPS 웹으로 옮긴다. 1단계 DB는 SQLite와 D1/R2를 전제로 했지만, 어느 플랫폼을 어떤 요금제로 설계할지는 정해야 한다. 처음부터 유료를 전제로 하면 비용 승인 없이 설계가 앞서고, 플랫폼을 미루면 WEB0·WEB1이 결정을 못 한다.

## 선택지

1. Cloudflare Workers·D1·R2를 무료 요금제로 설계한다.
2. Vercel + Turso로 간다.
3. Cloudflare + 외부 DB로 간다.
4. 지금은 플랫폼을 정하지 않는다.

## 채택

1번. **지금은 Cloudflare 무료 요금제(Workers Free·D1 Free·R2 무료 구간)를 전제로 설계**한다. 유료 전환은 `stage-5.md` 9절 신호가 날 때만 사용자에게 묻고, Vercel + Turso는 탈출 대안으로 둔다.

## 이유

- 1단계 DB의 SQLite/D1/R2 전제를 그대로 승계한다.
- 월 $0로 시작해 사용자 비용 결정을 미루고, 무료 한도는 계측·경보로 관리한다.
- 플랫폼을 지금 정해 두어야 WEB0 코어 언어 시험과 WEB1 골격이 같은 전제에서 움직인다.

## 영향

- `stage-5.md` 1·9절, WEB0·WEB1·WEB12. 이 파일이 `stage-5.md`가 가리키는 `0005-web-platform.md`다. WEB1은 측정값·탈출 조건을 이 기록에 보태고, 플랫폼을 바꾸면 새 결정 번호를 쓴다.
- 무료 한도(D1 5GB·DB당 500MB, 25초 대기, 호출당 쿼리 50, R2 무료 구간) 안에서 설계한다.
- R2가 결제 수단 등록을 요구할 수 있으므로 WEB1 전에 확인한다.

## 재검토 조건

- 무료 한도 상시 초과, D1 DB 500MB 도달, 쓰기 경합으로 승인 5초 초과.
- Cloudflare가 SQLite 호환을 깨는 변경을 할 때.
- R2 결제 수단 등록이 필요해질 때.
- `stage-5.md` 9절의 유료 전환 신호가 날 때.
