# 0007. 결함은 SEL-12·13에서 재현하고 SEL-31에서 고친다

- 날짜: 2026-11-04
- 담당: SEL-12·13(재현), SEL-31(수정)

## 문제

현행 v0.15.6에는 자료 손실·답 유실·승인 오처리 계열의 결함 후보가 있다. 재현과 수정 범위를 결함마다 나누면 이슈가 늘고, 재현 없이 고치면 회귀를 증명하기 어렵다.

## 선택지

1. 결함마다 별도 이슈로 재현·수정한다.
2. 재현은 SEL-12·13에서 하고, 수정은 SEL-31 하나에서 한다.
3. 고치지 않고 기록만 한다.

## 채택

2번. 재현은 **SEL-12·13**, 수정은 **SEL-31 하나**. 게이트를 막는 자료 손실·답 유실·승인 오처리 계열은 xfail 없이 고치고, 나머지는 `defects.md`에 기록한다.

## 이유

- 재현 증거를 먼저 만들어야 같은 결함을 두 번 고치지 않는다.
- 이슈 하나 = PR 하나 원칙과 0단계의 이슈 예산(구현 10개)을 지킨다.
- 모든 결함을 0단계에 넣으면 게이트가 끝나지 않으므로, 차단 계열만 고친다.

## 영향

- 0단계 게이트의 "결함" 조건, `defects.md`, `tests/` 회귀 시험.
- 새로 발견된 결함은 심각도·처리 단계를 적고, 차단 계열이면 SEL-31 범위를 다시 확인한다.
- 결함 기록 양식은 `AGENTS.md`의 결함 기록 절을 따른다.

## 재검토 조건

- 새 결함 계열이 자료 손실·오답 승인과 같은 등급으로 확인될 때.
- SEL-31 수정이 2단계 착수를 막을 만큼 커질 때(분할 근거를 남긴다).
