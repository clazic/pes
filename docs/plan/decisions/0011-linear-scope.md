# 0011. Linear 내보내기 범위는 1단계 UI 결정 11을 유지

- 날짜: 2026-11-05
- 담당: SEL-23(1단계 UI), 6단계 외부 내보내기(예정)

## 문제

"할 일로"의 기본 목적지를 PES 다음 라운드로 둘지 Linear로 둘지, Linear 실제 연동을 3단계에 넣을지 정해야 한다. 범위를 넓히면 3단계 소통 기능에 외부 인증·영수증·권한이 들어온다.

## 선택지

1. 3단계부터 Linear 실제 연동을 넣는다.
2. 1단계 UI 결정 11을 유지한다: PES 다음 라운드 할 일이 기본, 3단계는 Linear 초안·복사만, 실제 연동은 6단계.
3. Linear를 기본 목적지로 하고 PES 할 일은 보조로 둔다.

## 채택

2번. **1단계 UI 결정 11을 그대로 유지**한다. "할 일로"의 기본은 PES 다음 라운드 할 일이고, Linear는 3단계에 초안·복사만, 실제 연동은 6단계다. 연구 내용을 자동으로 포함하지 않는다.

## 이유

- PES가 원본이고 외부 도구는 한 방향 내보내기다(`stage-1-api.md` 결정 17).
- 외부 영수증·중복 방지·응답 유실 확인은 6단계 범위다.
- 3단계 U5는 프롬프트 복사·맥락 전달에 집중하고, Linear 연동을 끌어오지 않는다.

## 영향

- `stage-1-ui.md` 결정 11, 3단계 U5·U9, 6단계 외부 내보내기(E1).
- 6단계에서 Linear 범위를 넓히려면 새 결정을 남기고 API·영수증·권한을 설계한다.

## 재검토 조건

- 6단계 외부 내보내기 착수 시.
- 사용자가 3단계에서 실제 Linear 연동을 명시적으로 요구할 때(범위·비용·권한을 다시 묻는다).
