# 0008. 저장소 공개 유지

- 날짜: 2026-11-05 (공개 전환 2026-11-04)
- 담당: SEL-16, 전체

## 문제

이 저장소에는 PES 개발 코드·계획·합성 fixture만 두어야 한다. 비공개로 돌리면 실제 자료 유입 위험은 줄지만 공개 CI·협업·재현성 이점을 잃는다. 반대로 공개를 유지하면 실제 자료·실키가 커밋·이슈·PR·로그에 들어가지 않도록 규율이 필요하다.

## 선택지

1. 비공개로 전환한다.
2. 공개를 유지한다.
3. 일부 문서만 공개한다.

## 채택

2번. **저장소는 공개로 유지**한다. 실제 `~/pes-projects`·`~/.pes/`는 읽지 않고, 실제 자료·실키·기관명은 fixture·로그·문서·커밋·PR에 넣지 않는다.

## 이유

- 2026-11-04 공개 전환이 완료됐고, 매 PR CI와 새 세션 재현을 공개 전제로 한다.
- 공개 저장소라는 사실이 비밀 분리 규율을 강제한다. 테스트는 임시 `HOME`·`PES_HOME`으로 격리한다.

## 영향

- `AGENTS.md`의 금지·격리 규칙, SEL-16 공개 점검, 시크릿 스캔, 합성 fixture만 사용.
- 0004의 CI와 함께 유지된다. 공개 저장소에 올라가는 모든 내용이 공개된다고 가정한다.
- 설계·계획 문서에도 식별 가능한 실제 자료를 쓰지 않는다.

## 재검토 조건

- 기관 요구·법적 제약으로 공개할 수 없는 자료를 저장소에서 다뤄야 할 때.
- 공개 저장소 운영이 협업·보안상 불리하다고 확인될 때.
