# 결정 기록

설계·개발 결정을 한 건씩 남긴다. 논의안(`docs/plan/discussion/`)과 합의된 계획(`docs/plan/stage-N.md`)은 배경이고, 여기에는 **채택한 결정**만 적는다.

## 양식

파일 이름: `<번호>-<짧은-이름>.md` (예: `0001-test-isolation.md`). 아래 7항목을 모두 채운다.

```markdown
# <번호>. <결정 제목>

- 날짜: YYYY-MM-DD
- 담당: (이슈 번호 또는 이름)

## 문제
무엇을 정해야 하는가. 지금 무엇이 불편하거나 위험한가.

## 선택지
1. …
2. …

## 채택
고른 안.

## 이유
왜 이것인가. 비교 기준과 근거.

## 영향
바뀌는 코드·문서·테스트·운영. 뒤따르는 일.

## 재검토 조건
어떤 상황이 되면 다시 본다.

## 상태
제안 / 채택 / 폐기 (날짜)
```
