# 0022. 모르면 찾고, 못 찾으면 "확인하지 못함" — 추측 금지, 출처 필수

- 날짜: 2026-11-13
- 담당: 사용자 지시

## 문제
`skills/core/SKILL.md`는 출처 없는 판단·추정을 "(판단)" "(추정)" 표시를 붙여 쓰도록 허용했다. 그러면 AI가 모르는 내용을 그럴듯하게 채울 수 있다. 보고서는 모든 문장에 출처가 따라가야 한다.

## 선택지
1. 지금대로 "(추정)" 표시를 붙이고 허용한다.
2. 모르면 먼저 찾고(웹·원문·KOSIS·법령·VWorld), 찾으면 출처를 단다. 찾아도 없으면 "확인하지 못함"으로 쓰고, 추측은 쓰지 않는다.

## 채택
2. 모든 단계(기획·조사·분석·집필·검증·산출)에 적용한다.

덧붙임(2026-11-14): 1차 출처(공공기관 원문, kosis·law·vworld)를 먼저 쓴다. 2차 출처(블로그·커뮤니티·뉴스 요약)는 1차 출처를 찾지 못했을 때만 쓰고 note에 "2차 출처"라고 적는다.

## 이유
사용자 지시다(2026-11-13). 추측을 표시만 하고 남기면 읽는 사람이 놓치기 쉽고, 검증 단계의 부담이 커진다. 찾은 출처나 "확인하지 못함"만 남기면 빈 곳이 그대로 드러난다.

## 영향
- `skills/core/SKILL.md` 「근거 기록」, `agents/researcher.md`·`writer.md`·`reviewer.md`의 규칙을 바꾼다.
- "(판단)"은 분석·종합에서 근거 항목을 links로 잇는 경우에만 남는다.
- `confidence` 값은 그대로(high·medium·low)다. 찾지 못한 것은 본문 "확인하지 못함"과 open_questions "찾지 못함: …"으로 드러낸다.
- PES web(`pes-web`)은 같은 규칙을 서버에서 강제한다: 출처 없는 내용·"(추정)"·빈 출처를 받지 않는다.
- 뒤따르는 일: 플러그인 `merge`에서도 같은 검사를 할지 따로 정한다(동작 변경이라 이 결정과 나눈다).

## 재검토 조건
"확인하지 못함"이 너무 많아 보고서가 쓸모없어지거나, 사람이 명시적으로 추정을 요청하는 보고서 형식이 생기면 다시 본다.
