## 3. 고친 내용 요약

- **질문**: 기본값 미선택, 묶음 제출 주 동작, 옛 답 보기, 상태·오류 문구.
- **첨언**: 앵커 4상태, 프롬프트 복사, B 접수 상태, 할 일 기본값.
- **가정·결정·반영**: 결정 기록 표, applied 증거, 미제출/0건.
- **Go·인쇄**: 끄기·전송 내역·회수 불가·자동 재시작 없음, 인쇄 범위·판별 manifest.
- **배치·접근성**: 2영역 상태·키보드, 모바일 편집 제한, 200% 확대 분리.
- **기존 화면·Linear**: 병행·고정 HTML 보존, Linear 실제 연동 없음.

## 4. 비차단 메모

- F14는 설계서의 검수 집계 문구(“동의 15·보완 19·반대 0”)를 바로잡는 항목이라 정적 시안의 화면 요소가 아니다.
- 2영역 탐색은 계획서의 “아이콘 줄”을 점(dot)+이름+상태의 compact 행으로 구현했다. 아이콘 이미지가 필요하면 U1에서 교체한다.
- WEB/3단계 구현 전 시안이므로 실제 명령·API·저장은 연결하지 않았다. 모든 데이터는 합성이다.
