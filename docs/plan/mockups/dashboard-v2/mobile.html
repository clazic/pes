휴대폰 규칙

  • 엄격해지는 동작은 휴대폰에서도, 느슨해지는 동작은 데스크톱에서. 끄기·멈추기는 바로 되고, 다시 켜기·다시 허용·다시 열기는 데스크톱과 재인증을 거칩니다(10절 질문 3).
  • 휴대폰 판단은 화면 폭과 굵은 포인터(손가락)를 함께 봅니다. 데스크톱을 200%로 확대해 폭이 좁아진 것만으로 동작을 숨기지 않습니다.
  • 누르는 곳은 44px 이상, 입력 글자는 16px 이상(확대 방지), 한 화면에 한 질문, 진행 막대와 “n / 전체”를 함께.
  • 승인 재인증은 그 승인 한 건(프로젝트·단계·고정본)에만 쓰이고, 시간이 지나면 다시 묻되 입력은 지우지 않습니다.
  • 초안은 같은 탭에만 있습니다(새로고침 보존). 앱을 닫거나 다른 기기로 옮기면 남지 않는다고 처음 답할 때 한 번 알려 줍니다.
