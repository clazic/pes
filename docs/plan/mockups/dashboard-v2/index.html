주소는 초안입니다. 작업 공간 주소는 1단계 U1의 /p/<프로젝트>/e/<판>/s/<단계>/r/<라운드>를 따릅니다.

상태 표기 — 모양 9가지 + 글자 + 색

  • 됨·켜짐
  • 진행 중
  • 내 차례
  • 주의
  • 막힘·실패
  • 꺼짐·금지
  • 미상·미확인
  • 쉼·유예
  • 아직·건너뜀

색만으로 구분하지 않습니다. 모양은 테두리로 그려 고대비(강제 색) 모드에서도 남습니다. 글자 대비는 흰 바탕 기준 본문 16.5:1, 보조 글자 5.8:1, 강조 6.8:1, 입력 테두리 4.6:1입니다.

방식 A PES가 Go를 직접 부름 · 방식 B 내 컴퓨터 AI

점검한 것

  • 배치: 1440 이상 3영역, 1280~1439 짧은 이름 줄로 접은 2영역, 1280 미만 한 열(보기 전환, 열린 질문이 기본), 휴대폰은 굵은 포인터일 때만 편집 도구를 숨김(200% 확대는 숨기지 않음).
  • 키보드: 건너뛰기 링크, 모든 동작은 기본 단추·링크·입력, 초점 테두리 2px, 비활성은 aria-disabled와 이유 문장(초점은 받음), 스위치는 role="switch".
  • 화면 읽기: 영역 이름, 표 제목·열 제목, 계기는 숫자를 담은 이름, 갱신 알림 문장(role="status").
  • 내용: 이모지 0, 합성 예시만, 실제 경로·키·세션 번호 없음. 검사 스크립트(외부 자원·이모지·경로·id 짝)를 통과했습니다.
