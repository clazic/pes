확인 대화 상자(예시) · 소유자만

“내부 검토 의견(가상).docx”의 AI 참조를 끌까요?

바뀌는 것

  • 지금부터 방식 A의 Go 호출 맥락에서 뺍니다.
  • PES를 거치는 방식 B 도구(MCP)와 브라우저 보조(WebMCP) 응답에서 뺍니다.
  • 내 컴퓨터 도우미가 이 파일을 AI 작업 폴더로 받지 않습니다.

바뀌지 않는 것

  • 이미 나간 내용은 회수되지 않습니다. 나간 기록 2건: 11-04 14:10 방식 A 기획 R1 · 11-04 16:02 Claude Code가 PES를 거쳐 읽음.
  • 내 컴퓨터 AI 작업 폴더에 이미 받은 사본 1개가 있습니다. 저절로 지우지 않고, 도우미가 “사람용 폴더로 옮기기”를 제안합니다.
  • 이 파일을 근거로 쓴 결과물 2개(조사 노트 v3·v4)에 “AI 참조를 끄기 전에 쓰인 근거” 표시가 붙습니다.
  • 사람은 계속 열어 보고 직접 인용할 수 있습니다.

끄기는 바로 적용됩니다. 다시 허용은 소유자가 같은 확인을 거쳐야 하고, 5단계 웹에서는 재인증도 받습니다.
