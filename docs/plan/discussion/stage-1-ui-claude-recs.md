## A. 두 의견이 같은 것 (그대로 채택)

1. 질문 폼 페이지 → **프로젝트 작업 공간 하나**(셸: 프로젝트·판·단계/라운드·실행 상태·전송 칩·명령 / 가운데: 결과 글+첨언 / 오른쪽: 질문·가정·대화)
2. **열린 질문이 있으면 질문이 기본 작업면**. 질문 카드에서 고치기·더하기·빼기·질문별 의견·중요도·기본값·재확인 필요
3. 결과 글은 **읽기 전용 + 선택 도구**(첨언 / AI에게 묻기 / 할 일로). 앵커 상태 exact/moved/ambiguous/lost를 숨기지 않음
4. 가정·결정·반영 내역은 **표**. 해결 ≠ 적용, applied는 증거 필수
5. **Ctrl/Cmd+K 하나의 동작 목록**, 같은 입력에서 AI 질문으로 전환
6. **프롬프트로 복사는 방식 B의 기본 통로**, 복사 전 포함·제외·경고 미리보기
7. **전송 허용 칩 항상 표시, 끄기 스위치는 소유자 사람만**, 끄기가 이미 나간 자료를 회수하지 않음을 분명히
8. 범위 인쇄(라운드/단계/판), 봉인 스냅샷 기준 고정본, A4·표 머리 반복·흑백 대비
9. 전송 허용 / 실행 / 답 제출 / 단계 승인 / 반영 완료는 **서로 다른 사실** — 버튼·문구도 나눔
10. 제출·승인·정책 변경은 **서버 영수증 뒤에만 성공 표시**. 펼침·로컬 초안만 즉시 반영
11. 2단계 PR 18은 현재 화면을 DB/API로 바꾸기만(새 디자인 없음). 새 작업 공간은 3단계
12. 접근성(키보드·대비·한글 IME·200% 확대·색 비의존)은 **각 기능의 완료 조건**
13. 새 DB 표를 만들지 않음 — 현 54개 표·읽기 모델·계산으로 해결, 부족하면 SEL-21로
