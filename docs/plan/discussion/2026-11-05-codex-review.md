A의 프로그램/로컬 runner 제거·provider 고정/모델 선택·폴백 금지, B 여섯 도구·도우미·양방향 상태 표시, REF1/MAT1·기본 allow·엄격한 쪽 우선, TS 단일화·0.15 동결/이전 방향은 문서에 있다. ‘한 방향’이 남아 있는 **프로젝트 원본 절단 이전(WEB9)** 과 **Linear/Notion export(E1/E2)** 는 B의 자료 양방향 연결과 다른 계약이므로 문자열만으로 잘못됐다고 판단하지 않았다. 다만 WEB9는 원본 권한 이전, WEB15는 같은 웹 원본에 대한 버전/파일 교환이라는 경계를 실행 원고에서도 명확히 해야 한다.

최종 판정: **필수 항목 수정 후 승인**. 언어 선택 자체는 이미 TypeScript로 결정됐으며 다시 선택받을 사항이 아니다. 플랫폼/조합·런타임 실측 결과, 검색 수단의 실제 선택·자료 전달 범위, 카드·월 총비용과 회수/중단 절차는 검토 가능한 결과가 나온 시점에 확정해야 한다.
