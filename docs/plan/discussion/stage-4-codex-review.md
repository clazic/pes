- 실제 `~/pes-projects`·`~/.pes/`의 파일 내용은 열람하지 않았다. 코드·계획서는 수정하지 않았고, 이 검수 파일만 작성했다. Linear 조회·이슈 생성·모델 호출·프로젝트 시험은 하지 않았다.

**총평: 수정 후 합의 가능.** 1단계가 4단계로 넘긴 다섯 기능과 기존 화면 기본 전환은 모두 들어 있다. 다만 PR 6의 책임을 새 PR로 다시 배정한 부분, 실제 DDL과 다른 계보 설명, 반대 의견의 독립 검토 강제, 새 명령의 서버 검증·교차 시험 책임을 먼저 정리해야 한다. 사용자 결정 목록도 구현 선택과 비용 승인을 분리해야 한다.

판정은 **동의**(그대로 수용), **수정**(방향은 수용하되 무엇을 왜 바꿔야 하는지 명시), **반대**(해당 제한·배정을 채택하지 않음)로 쓴다. 중요도는 높음(합의·정확성·업무 검증), 보통(누락·검증 가능성·운영 경계)으로 구분한다.

## 5. 사용자 결정 목록은 비용·되돌리기 어려운 일뿐인가

**현재 다섯 행을 그대로 사용자 결정으로 올리는 데는 동의하지 않는다.** 실제 유료 실행·자료 사용·원고 권한 경계는 사용자에게 남기고, 구현·가역적인 화면 설정·일반 검토 UX는 합의된 범위에서 개발자가 구체화한다. 아직 답하지 않은 비용 결정을 “추천으로 진행”해 승인된 것으로 간주해서는 안 된다.

| 번호 | 6절 항목·대상 줄 | 판정 | 무엇을·왜 |
|---|---|---|---|
| E01 | 이월 새 표·새 열, 169행 | 반대 | **사용자 결정 표에서 빼고 DB/API 설계 검토로 옮긴다.** 현재는 구현 전 설계이므로 새 표 대 기존 관계의 선택 자체가 사용자 비용·불가역 행동은 아니다. 조회·제약·복원·D1 검증으로 개발자가 결정 기록을 남길 일이다. 향후 실제 데이터 손실·호환성 포기를 수반하는 이전이 필요하면 그 구체적 영향과 복구안을 사용자에게 올린다. |
| E02 | AI 직접 편집 권한, 170행 | 수정 | **사용자 결정으로 유지할 수 있다.** 다만 “항상 허용이 위험”하다는 추상 설명 대신, 현재 원고의 새 버전을 사람 수락 없이 채택할 수 있는 범위·run/객체별 허가·회수·승인본 금지·복구 방법을 보여 준다. 기존 결과 제출 전체의 권한을 다시 정하는 질문으로 넓히지 않는다(A16). 미확정이면 제안 모드로 구현하고 허가가 있기 전 AI 직접 편집을 켜지 않는다. |
| E03 | 반대 의견 효력, 171행 | 수정 | 기본 **참고+명시적 확인+사람 최종 결정**은 일반 검토 UX 합의로 옮긴다. AI 거부권은 비목표이고 이미 사람만 승인하므로 그 권한을 다시 선택하게 하지 않는다. 매 승인마다 별도 유료 reviewer를 강제하거나 사람도 해제 못 하는 차단을 도입하려는 경우에만 비용/권한 변경을 구체적으로 사용자에게 묻는다. A13의 reviewer 강제는 채택하지 않는다. |
| E04 | 기본 화면 대체 방식, 172행 | 수정 | 프로젝트별 opt-in·기능 동등성 뒤 기본·같은 DB/API 롤백은 **구현·완료 게이트**로 옮긴다. 가역적 기본 화면 선택을 불가역 결정처럼 올리지 않는다. 사용자에게 필요한 별도 결정은 실제 자료 파일럿 허용 범위(도입한다면), 또는 나중의 legacy 기능/기록 제거다. 기존 화면 기본 전환 자체는 이미 4단계 목표다(UI 47행). |
| E05 | 맛보기 유료 실행, 173·182행 | 수정 | **비용 결정으로 유지한다.** 생성 빈도뿐 아니라 SEL-18 측정 뒤 run·단계·프로젝트 누적의 **실제 상한 값**, 유료 합성 시험 한도, reviewer/재시도/unknown 예약 처리까지 사용자가 확인해야 한다. 값이 없으면 유료 실행을 시작하지 않는다. B 외부 비용은 PES가 집행할 수 없다는 한계도 함께 표시한다(runners 64~66·84행). |
| E06 | “추천으로 진행” 공통 문구, 165행 | 수정 | 구현 추천은 합의 검토 후 진행하되, **미확정 비용 승인이나 실제 자료 사용 허용은 묵시 승인으로 처리하지 않는다.** 110행의 실제 프로젝트 확인을 남긴다면 여기에서 원본/사본·범위·보관/로그·외부 전송 여부와 중단·복구 조건을 정해 별도 허용 대상으로 연결한다. 현 검수 요청은 실제 자료 열람·시험을 허용하지 않는다. |
