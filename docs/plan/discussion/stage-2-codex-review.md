## 6. 실제 프로젝트·설정 내용 유입 여부

| 확인 항목 | 판정 | 확인 범위·결과 |
|---|---|---|
| S2의 경로 표기 | 동의 | `~/pes-projects`, `~/.pes/pes.db`, `~/.pes/objects/`, 백업/실행 workspace의 일반 경로·placeholder는 설계 또는 코드의 기본 경로다. 이 표기 자체를 실제 디렉터리 내용 유출로 판정하지 않는다. |
| 실제 자료로 식별되는 내용 | 동의 | **S2 226줄에서 실제 프로젝트 slug·개별 프로젝트 목록·실제 본문/질문/답·개인 설정값·키·실측 프로젝트 통계를 발견하지 못했다.** 깨진/2MB fixture 요구는 S0:23에 이미 있는 합성 시험 기준이다. 이 검수 문서에도 실제 디렉터리 내용은 넣지 않았다. |
| 확인의 한계 | 수정 | ‘실제 자료 없음’은 **초안에서 식별되는 내용 없음**이라는 범위로 표현한다. 원문 디렉터리를 읽지 않았으므로 초안 작성자가 과거 실제 폴더를 읽었는지, 모든 값의 출처가 무엇인지까지 보증할 수 없다. 실제 자료와의 일치 검증을 위해 금지된 디렉터리를 열지 않는다. |
| 향후 파일럿 산출물, S2:18, 70, 179 | 수정 | 실제 접근 허용은 실제 자료의 공개 저장소/CI/테스트/공개 로그 반입 허용과 다르다. 실제 manifest·원문 경로·이전 보고서는 로컬에 두고, PR에는 합성 재현·익명화된 결과만 남기는 귀속을 PR11/12/22에 명시한다. 이는 실제 자료 파일럿 허용 시 적용할 조건이며 이번 검수에서 실제 접근을 요청하지 않는다. |

확정 전에는 위 반대 항목과 삭제 정책·API/run 제어·화면 초안/실행 표시·복원 격리의 누락을 기존 PR에 반영하고, 선행 그래프·병렬 묶음·완료 게이트를 함께 재대조해야 한다. 이 검수는 사용자 결정이나 실제 구현 성공을 대신하지 않는다.
