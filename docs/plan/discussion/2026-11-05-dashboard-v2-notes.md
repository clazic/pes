## 5. 시안 점검 기록

- **만드는 방법**: 공통 스타일 한 벌을 각 시안에 같은 블록으로 넣어 자기완결로 만들었다(외부 글꼴·스크립트·그림 없음). 만들 때마다 검사 스크립트가 외부 자원, 이모지·그림 문자, 사용자 절대경로·실제 PES 홈 문자열, 그림 태그, 중복 id, `label for`·`aria-*` 참조, 태그 짝을 확인했고 7개 모두 통과했다. 스크립트는 저장소에 넣지 않았다.
- **화면 확인**: Chromium 기반 브라우저로 1440 · 1366 · 1100 · 720 · 390 폭을 캡처해 눈으로 봤다. 가로 넘침 없음. 고친 것: 프로젝트 목록·사용량 표의 상태 칩이 칸 폭으로 늘어나던 것, 마법사 결과 목록의 칸 어긋남, A 마법사 예시 프로젝트가 B 작업 공간 프로젝트와 같은 이름이던 것(D19), 범례 굵기.
- **대비 계산**(상대 휘도): 본문 16.45:1, 보조 5.78:1(회색 바탕 5.33:1), 강조 6.84:1, 초록 5.32:1(옅은 초록 바탕 4.69:1), 빨강 6.51:1, 주황 5.93:1, 입력 테두리 4.56:1, 방식 A 배지 5.60:1, 방식 B 배지 7.13:1, 계기 채움/바탕 5.37:1 · 3.73:1 · 4.51:1. 문턱 선은 빨간 채움 위에서 2.65:1이라 흰 테두리 2px로 바탕과 떨어뜨렸다.
- **못 한 것**: Windows 맑은 고딕 렌더링, 실제 한글 IME, NVDA·VoiceOver 낭독, 인쇄 쪽 나눔. 시안은 정적이라 초점 가두기·갱신·영수증 동작은 문서로만 정했다.
