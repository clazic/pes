# 2~6단계 계획 승인 요약

- 읽는 사람: 한국어 정책 연구자(개발자 아님)
- 목적: 2~6단계 계획을 승인하기 전에 무엇이 달라지고, 무엇을 정해야 하는지 빠르게 확인
- 0단계는 확정됐고, 1단계 설계는 승인됐습니다. **2~6단계 계획은 2026-11-05 사용자가 승인했습니다.**
- 실제 `~/pes-projects`·`~/.pes/` 자료는 읽지 않았습니다. 모든 예시는 합성 자료입니다.

## 1. PES가 무엇으로 바뀌나

지금 PES는 프로젝트 폴더의 `project.json` 파일 하나에 모든 상태를 두고, AI가 만든 결과를 HTML 파일로 찍어 냅니다. 앞으로는 상태를 **데이터베이스(DB, 자료를 쌓아 두는 저장소)**에 쌓고, 화면과 AI 작업자가 같은 **API(프로그램끼리 주고받는 정해진 요청·응답 규칙)**로 일합니다. 사람은 웹 화면에서 답·승인·의견을 남기고, AI는 정해진 방식으로만 결과를 올립니다. 그래서 보고서의 2판·3판, 여러 사람, 다른 AI, 웹 이전이 가능해집니다.

용어: **A**는 PES가 웹(또는 로컬)에서 OpenCode Go API를 직접 호출해 AI를 실행하는 방식, **B**는 사람 컴퓨터의 Claude Code·Claude 앱·Codex CLI·OpenCode TUI·Codex 앱·OpenCode 앱 같은 외부 AI가 프로젝트를 만들어 PES에 등록하고 웹에서 작업하는 방식입니다. **B는 자료·진행·스케줄이 내 컴퓨터와 웹 사이에서 양방향으로 오갑니다.** 연결 통로는 **PC 도우미↔웹 WebSocket/HTTP, AI 도구↔PES MCP/API, 브라우저 탭 안 보조만 WebMCP**입니다. **이슈 하나 = PR 하나**는 작업을 한 번에 하나씩 검토·병합한다는 뜻입니다. **U1~U6·REF1·MAT1**은 3단계, **U7~U12**는 4단계, **PR1~26**은 2·4단계, **WEB0~15**는 5단계, **E/M/H/X와 G3**는 6단계 작업 묶음입니다. CLI는 명령줄 도구, 스킬은 AI 작업 지침, TUI는 터미널 화면, worker는 작업자, 게이트는 단계 완료 확인, legacy는 이전 화면(`/legacy`), 계약 시험은 정해진 요청·응답이 같은지 보는 시험입니다.

### 웹 연결 통로 3가지

| 통로 | 누가 누구와 | 하는 일 | 하지 않는 일 |
|---|---|---|---|
| **웹소켓(연결 도우미)** | 내 컴퓨터 도우미 ↔ 웹 PES | 새 작업·자료·답 즉시 알림, 진행·스케줄·동기화 상태. 끊기면 커서부터 재접속 | 큰 파일 전송, A 실행 |
| **MCP** | 내 컴퓨터 AI 도구 6가지 ↔ PES | 맥락 읽기·결과 제출·질문 등 PES 기능의 표준 약속 | PC↔웹 실시간 통로 자체, 승인·사람 답 대행 |
| **WebMCP** | 브라우저 탭 안 AI ↔ 열린 PES 페이지 | 페이지 기능을 제한 allowlist(읽기·초안·첨언)로 사용 | PC↔웹 통로, 승인·정책·토큰·사람 답 제출 |

큰 파일은 웹소켓이 아니라 HTTP 업로드/다운로드(R2·Blob 서명 URL)를 씁니다.

### 웹호스팅 후보

| 후보 | 조건 | 판단 |
|---|---|---|
| Cloudflare 무료 | Workflows step CPU 10ms·step 1,024·subrequest 50, D1/R2/DO 웹소켓 | 기본 후보 |
| Vercel Hobby+Turso | 함수 300초, Active CPU 월 4시간, TS 실행, **비상업 PES라 Hobby 제약 충족(실제 배포 주체의 personal 조건은 WEB0 확인)** | 동등 후보 |
| 작은 VPS(Oracle 무료→Hetzner 월 총액은 WEB0 견적) | 긴 루프·SQLite·웹소켓 그대로, 운영 부담 | 대안, 비용은 사용자 결정 |

**WEB0에서 세 후보를 같은 합성 시나리오로 실측**해 고릅니다. 판정 기준은 ① A 한 라운드 ② TS 실행성 ③ SQLite 계약 ④ 월 여유 ⑤ 카드 등록 ⑥ 상시 양방향 통로 ⑦ 운영 부담 ⑧ 월 비용입니다. 추천은 무료로 다 되면 Cloudflare, 막히면 작은 VPS, Vercel은 중간 대안입니다. 엮을 때는 **Cloudflare 중심+계산만 교체(X)** 를 추천 초안으로 두고, 자료 원본은 한 곳에 둡니다. **플랫폼 공통 계약과 Cloudflare 기준 구현을 구분**하고, WEB0 결과를 WEB1~14의 DB·파일·실행기·실시간·백업·비용 계기 설계에 인계합니다. 유료 안은 비용 승인 뒤 그 예산으로 시험합니다.

## 4. 사용자가 정할 것

### 4.1 돈·자료·되돌리기가 걸린 결정

한 번 정하면 단계마다 다시 묻지 않습니다. **Codex CLI·OpenCode TUI를 2단계에서 붙이는 것, TypeScript 단일 언어와 0.15 Python 이전(0016), 파일별 AI 참조 기본 allow, B 양방향·통로 분리는 2026-11-05 이미 정했습니다.** 아래 표는 남은 결정만 묻습니다. **실제 자료 사용 허용 기록**은 "어떤 프로젝트의 어떤 자료를 어디로 보내도 되는지" 적는 장부입니다.
