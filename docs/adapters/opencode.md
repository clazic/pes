# 어댑터 노트 — OpenCode

중립 표기로 쓴 스킬·에이전트·명령 문서를 **OpenCode**에서 쓰려는 사람을 위한 노트다. 지금은 OpenCode용 어댑터(문서 변환·도구 연결)가 **없다**. 아래는 필요한 대응과 아직 안 되는 것을 적은 것이고, 이름만 바꿔 동작한다고 말하지 않는다.

## 환경과 무관한 것

- pes 명령(`context`·`claim`·`submit`·`merge`·`ask`·`note`·`qa`·`approve` 등)은 환경과 무관한 같은 명령이다. 상태는 이 명령으로만 읽고 쓴다.
- 연구 절차(조사 항목·출처 원문 확인), 독립 검토(reviewer 역할), 검증(verifier 역할)의 절차와 `agents/*.md`의 역할 지침은 환경과 무관한 내용이다.
- 질문·승인은 로컬 대시보드와 질문 폼(웹)이 원본이다.

## 직접 옮겨야 하는 것

| 문서의 중립 표기 | OpenCode에서 할 일 |
|---|---|
| 서브에이전트를 띄운다 (researcher·writer·verifier·reviewer) | OpenCode의 세션/프롬프트로 역할 지침 파일(`agents/*.md`)을 읽혀 띄운다. 한 번에 최대 5개 같은 제한은 사용자가 정한 모델과 한도에 맞춘다 |
| 가벼운 모델 / 강한 모델 | 사용자가 고른 모델 하나를 쓴다. 모델 이름은 문서에 없다 |
| 답 대기 (`watch`) | `Monitor` 같은 도구가 없다. `pending`을 주기적으로 읽거나 PES의 입력 API를 쓴다 |
| 형식 변환 (hwpx·docx·pdf·slides) | 같은 이름의 변환 도구가 없다. 사람이 직접 변환하거나 "변환하지 못했다"고 알린다 |
| 플러그인 경로·세션 표시 | `PES` 실행 경로와 세션 ID를 사용자가 직접 정해 환경변수로 넘긴다 |
| 사람에게 고르게 하기 | 질문 폼을 쓴다. 서버를 띄울 수 없으면 채팅으로 선택지를 보이고 답을 `chat`으로 기록한다 |

## 한계 (아직 안 되는 것)

- Claude 표기(`/pes:*` 명령 진입점, `${CLAUDE_PLUGIN_ROOT}`, `pes:*` 서브에이전트 이름)를 OpenCode 표기로 바꿔 주는 자동 변환은 지원하지 않는다. 변환 지원을 주장하지 않으며, 지금은 사람이 문서를 읽고 직접 옮긴다.
- 독립 검토를 건너뛰지 않는다. 별도 세션으로 reviewer를 띄울 수 없는 설정이면 사용자에게 알린다.
- `set`(단계 요약·변경점·남은 일·설정·점검, 최종 요약·결론)은 지금 옛 방식(v0.15) 프로젝트에서만 쓸 수 있다. DB 경로(`PES_DB_CORE=1`)에서는 대응 명령이 생길 때까지 한국어 이유와 함께 거부되고 아무것도 바뀌지 않는다 — 우회해서 다른 명령에 끼워 넣지 않는다.
- OpenCode 환경의 실제 합성 실행은 아직 검증하지 않았다.
